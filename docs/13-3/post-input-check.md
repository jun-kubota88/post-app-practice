# 投稿編集画面 入力チェック表

| 画面 | 項目 | 必須 | 文字数・桁数 | 形式・値の範囲 | ほかの項目との関係 |
|:-----|:-----|:-----|:-------------|:---------------|:-------------------|
| 投稿編集画面 | タイトル | 必須 | 255文字以内 | - | - |
| 投稿編集画面 | カテゴリ | 必須 | - | カテゴリのどれか1つ | - |
| 投稿編集画面 | 本文 | 必須 | 上限なし | - | - |

タイトルの255文字は、決めて選んだ数字ではありません。title の列を string 型で作ったことで決まった長さが、そのまま入力チェックにも出てきたものです。
