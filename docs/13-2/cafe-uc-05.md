#### UC-02: 注文を受け渡し済みにする

- **アクター**: 店員

- **事前条件**: 
  - 注文が登録されている
  - 店員が注文一覧を表示している

- **基本フロー**:
  - 1.店員が注文一覧を表示する
  - 2.システムが注文一覧を表示する
  - 3.店員がお客さまへ商品を渡す
  - 4.店員が対象の注文を選択する
  - 5.店員が受け渡し済みに変更する
  - 6.システムが注文状態を受け渡し済みに更新する

- **代替フロー**: 4a. 対象の注文が見つからない場合、処理を中止する

- **事後条件**: 注文状態が受け渡し済みになっている

- **受け入れ条件**: 
  - [ ] 店員が注文一覧を確認できること
  - [ ] 対象の注文を選択できること
  - [ ] 注文状態を受け渡し済みに変更できること
  - [ ] 更新結果が保存されること
